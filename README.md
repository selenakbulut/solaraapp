
# Solar Production Forecast

Python ile geliştirilen güneş enerjisi üretim tahmin uygulaması.

## Kullanılan teknolojiler
- Python
- Streamlit
- SQLite
- Open-Meteo API
- Pandas

## Özellikler
- Saatlik hava durumu tahminlerinin alınması
- Hava verilerinin SQLite üzerinde önbelleğe alınması
- Panel sıcaklığı ve üretim kayıplarının hesaplanması
- Panel eğimi ve azimutuna göre üretim tahmini
- Saatlik ve günlük üretim grafikleri
- Santral parametrelerinin web arayüzünden değiştirilmesi

## Kurulum

pip install -r requirements.txt

## Çalıştırma

python database.py

streamlit run app.py

## Geliştirme durumu

Proje geliştirme aşamasındadır.
